# Juan Vega — Personal Portfolio

Personal portfolio website built to showcase my work, skills, and professional profile as a Systems Engineering student.

[View the live portfolio](https://juanvegarojano.vercel.app/)

---

## Built With

| | |
|---|---|
| Framework | React 19 + Vite |
| Language | TypeScript |
| Styling | Tailwind CSS v4 |
| Icons | Lucide React |
| Deployment | Vercel |

---

## Running Locally

### Requirements

- Node.js 20.19+ or 22.12+
- npm

---

## Editing Content

All portfolio content lives in `src/data/` — projects, toolkit, education, and contact channels. Project images go in `src/assets/`.
